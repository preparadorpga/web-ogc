# materiales/ · paquete cifrado de OGC Ventas

materiales, que no está en este repositorio, no se puede leer ningún documento. Lo publica
`ventas/publicar_materiales.py` y lo descarga cada hora el plugin «OGC Ventas» 1.1. No se edita a mano.
